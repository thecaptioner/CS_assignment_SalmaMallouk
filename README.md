# CS_assignment_SalmaMallouk
Code for the assignment of Computer Science for Business Analytics

This GitHub link contains the code for the assignment of the Master Course Computer Science for Business Analytics
For this assignment, a solution needs to be found for the scalability issue regarding finding duplicates in Web Shop products. 
The following steps have tried to be taken:
- Loading the data
- Creating Binary vectors
- Creating a signature matrix
- Performing LSH with minhashing
- Finding candidate pairs
- Performing Agglomerative Clustering
- Calculating F1 measures before and after clustering
